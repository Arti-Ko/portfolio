# Fantasy Football — SportTech

`SPORTTECH` · бизнес-анализ · user flow, продуктовая аналитика

Приложение фэнтези-футбола: пользователь собирает состав из реальных игроков
в рамках бюджета, назначает капитана и получает очки по фактической
статистике матчей.

## Исходный артефакт

Основа документации — user flow-диаграмма со свимлейнами
«Пользователь / Бэкенд / Внешний сервис». Она зафиксировала не только
последовательность экранов, но и то, что происходит на бэкенде за каждым
действием и где система зависит от поставщика спортивных данных.

Схема, разбор заложенных в неё решений и найденные пробелы —
в [user-flow.md](user-flow.md).

## Суть продукта

Пользователь регистрируется, выбирает любимые команды, попадает на
«футбольное поле» — визуальную расстановку своего состава. Из каталога
игроков он набирает 15 футболистов, укладываясь в бюджет и лимит игроков
из одного клуба, назначает капитана (его очки удваиваются) и фиксирует
состав до дедлайна тура.

Дальше начинается главное: во время матчей внешний сервис отдаёт события —
голы, передачи, карточки. Бэкенд начисляет очки по правилам, обновляет
глобальную таблицу и мини-лиги, где пользователь соревнуется с друзьями.

## Ключевые узлы, зафиксированные в схеме

| Узел | Что делает бэкенд | Почему это важно |
|---|---|---|
| Регистрация | Создание аккаунта: email / телефон / VK | Точка входа в воронку |
| Авторизация | Уведомление email / SMS | Подтверждение владения контактом |
| Каталог игроков | Отдаёт имя, клуб, позицию, цену | Основа всей игровой механики |
| Добавление игрока | Проверка бюджета и лимитов по клубу | Единственное место, где правила игры превращаются в ограничение |
| Утверждение состава | Фиксация 15 игроков | Точка невозврата до дедлайна тура |
| Начало матча | Внешний сервис отдаёт события | Зависимость, определяющая архитектуру |
| Расчёт очков | Начисление и обновление таблиц | Ядро ценности продукта |
