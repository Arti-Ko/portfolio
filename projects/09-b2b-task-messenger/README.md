# B2B веб-мессенджер клиентских задач

`B2B SAAS` · бизнес-анализ и пресейл · real-time, интеграция с CRM,
работа с персональными данными

Веб-мессенджер для управления клиентскими задачами с двусторонней
интеграцией с корпоративной CRM. Развитие работающего Telegram-бота в
полноценный продукт с ролями, личным кабинетом и веб-интерфейсом для
сотрудников.

## Задача

У заказчика работает Telegram-бот: клиенты ставят задачи кнопками и
оценивают выполнение. Клиентам удобно — они уже в мессенджере. Сотрудникам
неудобно: нет нормального интерфейса, нет ролей, нет истории в одном
месте.

Главное ограничение задачи — **нельзя ухудшить клиентский опыт**.
Telegram задал планку: мгновенная доставка, понятный интерфейс, ничего не
нужно устанавливать. Веб-мессенджер, который окажется медленнее или
сложнее, клиенты просто не примут и вернутся писать в бот напрямую.

## Ключевые требования

| Требование | Значение | Следствие |
|---|---|---|
| Параллельных сессий | 3 000 | Определяет выбор технологии real-time и схему масштабирования |
| Создание чатов | Автоматически при инициации сделки | Чат — не самостоятельная сущность, а часть жизненного цикла задачи |
| Интеграция с CRM | Двусторонняя | Нужна модель разрешения конфликтов версий |
| Уровень интерфейса | Не ниже Telegram | На мобильном — фактически выше: нужна установка как приложения |
| Персональные данные | ФИО, телефоны клиентов | 152-ФЗ: шифрование, журнал доступа |
| Роли | Клиент, сотрудник, администратор | Разграничение по видимости чатов и задач |

## Главное решение анализа

Заказчик формулировал задачу как «сделать веб-версию бота». Разбор
показал, что это не так: **бот остаётся**. Клиенты продолжают ставить
задачи в Telegram, потому что им там удобно, а веб-мессенджер решает
задачу сотрудников. Два канала работают параллельно над одной сущностью —
задачей.

Это меняет архитектуру: чат и задача становятся отдельными сущностями с
синхронизацией между каналами, а не единым интерфейсом с двумя
представлениями. Попытка «перенести всех в веб» провалилась бы на первой
неделе.
