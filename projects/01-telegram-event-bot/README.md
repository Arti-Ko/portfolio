# Telegram-бот регистрации на мероприятия

`BOTS` · бизнес-анализ · Telegram Bot API, Python, SQL, Google Sheets API

Автоматизация сбора заявок, напоминаний и опросов после мероприятий в Telegram.
Продукт заменяет связку «лендинг + форма + рассылка» одним ботом: пользователь
не покидает мессенджер от первого касания до обратной связи.

## Задача

Организатор проводит мероприятия регулярно, но каждый цикл собирается вручную:
форма в Google Forms, напоминания в личных сообщениях, опрос после события —
если до него вообще доходят руки. Заявки теряются между таблицей и перепиской,
явка не прогнозируется, обратная связь не собирается системно.

## Цели

| Цель | Метрика |
|---|---|
| Собирать заявки в Telegram без отдельного сайта | ноль внешних форм в воронке |
| Довести пользователя от просмотра до завершённой регистрации | конверсия 85%+ |
| Автоматизировать напоминания | 100% подтверждённых заявок получают T-24 ч и T-1 ч |
| Замерять качество мероприятия | NPS-опрос автоматически, без ручного запуска |

## Что сделано как бизнес-аналитиком

- **Conversation flow и сценарии диалога** — FSM-диаграмма состояний бота,
  включая обработку прерываний, возврата к предыдущему шагу и повторного входа
- **ТЗ на Telegram Bot API** — inline-кнопки, набор команд, deep links с
  параметром мероприятия, callback-контракты
- **Модуль автоматических напоминаний** — окна T-24 ч и T-1 ч, работа с
  часовыми поясами, лимитами Telegram и логикой освобождения мест
- **Форма пост-ивентного опроса** — NPS-шкала, ветка уточняющего вопроса для
  детракторов, сводные отчёты по мероприятиям
- **Интеграция с Google Sheets / Airtable** — CRM-учёт участников,
  маппинг полей, стратегия разрешения конфликтов при повторной синхронизации
